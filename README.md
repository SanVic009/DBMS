🐄 Dairy Management System

A web-based Dairy Management System designed to simplify and digitize daily dairy farm operations. This project helps farmers and employees efficiently manage cattle information, milk production records, and dairy-related activities through a clean and user-friendly interface.

The system reduces manual record keeping and provides an organized platform for monitoring livestock data and farm productivity.

⸻

🚀 Features

👨‍🌾 Farmer Module
	•	Add, update, and delete cattle records
	•	Maintain detailed information including:
	•	Cattle ID
	•	Age
	•	Vaccination status
	•	Track milk production data
	•	View milk production graph for the last three months
	•	Access government dairy schemes and useful resources
	•	View top performing farmers

🧑‍💼 Employee Module
	•	Secure login system for employees
	•	Manage dairy records
	•	Assist farmers with cattle and production data management
	•	Maintain overall system data integrity

📊 Data Visualization
	•	Bar graph displaying monthly milk production
	•	Structured tables for easy cattle record management

🌐 User Interface
	•	Split-screen login system for Farmers and Employees
	•	Clean and responsive design
	•	Separate CSS styling for modular UI components

⚙️ How to Run the Project
	1.	Clone the repository

git clone https://github.com/yourusername/dairy-management-system.git

	2.	Move the project folder to htdocs (XAMPP) or www (WAMP).
	3.	Start Apache and MySQL.
	4.	Import the database:
	•	Open phpMyAdmin
	•	Create a new database
	•	Import dairy.sql
	5.	Open the project in your browser:

http://localhost/dairy-management-system
